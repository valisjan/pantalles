# Pantalles

Aplicació independent per gestionar i mostrar les pantalles informatives de l’IES Josep Sureda i Blanes.

Comparteix el projecte Firebase `quota-e1424` amb Quota i Guàrdies, de manera que les jornades publicades a Guàrdies apareixen a Pantalles sense duplicar dades.

## Desenvolupament

```bash
npm install
npm run dev
```

La gestió s’obre amb `/?gestio=1&pantalla=sala-professorat`. El quiosc s’obre amb `/?pantalla=sala-professorat`.

## Desplegament

El repositori està preparat per importar-lo directament a Netlify. La configuració recomanada és el subdomini `pantalles.iessureda.com`.
